# 💰 Catatan Pengeluaran Harian

**Catatan Pengeluaran Harian** adalah aplikasi yang dibuat untuk membantu pengguna mencatat dan mengelola pengeluaran sehari-hari dengan mudah, sederhana, dan terorganisir.

Aplikasi ini memungkinkan pengguna untuk mencatat transaksi, menentukan kategori pengeluaran, melihat riwayat transaksi, serta memantau total pengeluaran.

## ✨ Fitur

* 📝 Menambahkan pengeluaran
* ✏️ Mengedit data pengeluaran
* 🗑️ Menghapus data pengeluaran
* 📋 Melihat riwayat pengeluaran
* 💰 Menghitung total pengeluaran
* 🏷️ Menentukan kategori pengeluaran
* 📅 Mencatat tanggal transaksi
* 🔍 Memantau pengeluaran dengan lebih mudah

## 🎯 Tujuan

Aplikasi ini dibuat untuk membantu pengguna agar lebih mudah dalam mengontrol dan mencatat keuangan sehari-hari.

Selain itu, project ini juga dibuat sebagai sarana untuk mempelajari dan mengembangkan kemampuan dalam membangun aplikasi.
